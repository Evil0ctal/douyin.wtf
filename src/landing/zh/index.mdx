## 这是什么

**Douyin_TikTok_Download_API** 是一个开源、自部署的[抖音](https://www.douyin.com)、
[TikTok](https://www.tiktok.com) 数据接口服务。你用一条 `docker compose up`
把它跑在自己的机器上。没有托管版、不用注册、没有配额，链路上也没有第三方。

它能取两个平台的作品、作者、评论、合集和搜索，下载视频和图集时拿到的是**无水印**的流
—— 它挑的是平台本来就提供的那条干净流，而不是「去掉」了什么。采集到的内容归档在
你自己的 PostgreSQL 里，所以上游删掉的作品，本地还读得到。

麻烦的部分它替你处理了，而不是丢给你：抖音的 `a_bogus`、`X-Bogus` 请求签名和 TikTok 的
签名都是纯 Python 实现；短链会先展开再对照白名单校验，然后才发出任何请求；作品 ID 会先按
平台自己的编码规则验一遍，所以一个不可能存在的 ID 不会浪费一次上游请求。

## 不用装任何东西就能试

<CardGrid>
  <Card title="在浏览器里" icon="laptop">
    <Steps>

    1. 打开 [demo.douyin.wtf](https://demo.douyin.wtf)，登录页已经替你填好演示账号。
    2. 登录进去，你的角色是 `demo`。
    3. 进 **调试台**，粘贴任意抖音或 TikTok 链接，点解析。

    </Steps>
  </Card>
  <Card title="在终端里" icon="seti:shell">
    不用注册：演示账号的口令是实例自己在 `/api/v1/auth/demo` 公布的。
    登录拿到的是会话 cookie，不是 bearer token。

    ```bash
    PASS=$(curl -s https://demo.douyin.wtf/api/v1/auth/demo | jq -r .data.password)

    curl -s -c jar -o /dev/null \
      -X POST https://demo.douyin.wtf/api/v1/auth/login \
      -H 'content-type: application/json' \
      -d "{\"username\":\"demo\",\"password\":\"$PASS\"}"

    curl -s -b jar -X POST 'https://demo.douyin.wtf/api/v1/parse?wait=25' \
      -H 'content-type: application/json' \
      -d '{"url":"https://www.douyin.com/video/7675505205047348543"}' \
    | jq '.data | {platform, kind, description}'
    ```
  </Card>
</CardGrid>

`?wait=25` 是让这次调用变同步的开关：它会挂住连接直到任务完成，然后用 `200` 把结果给你。
不加它就是 `202` 加一个 task id，那是正常的异步路径。这个实例的上限是 30 秒。

接口文档也不用登录就能看 ——
[`/swagger`](https://demo.douyin.wtf/swagger)、
[`/redoc`](https://demo.douyin.wtf/redoc)、
[`/openapi.json`](https://demo.douyin.wtf/openapi.json)，中英双语。

<Aside type="caution" title="演示站是什么，不是什么">
它只是一台小服务器，所有人共用，所以限流是**每 10 秒 30 次请求**；
超了会进入 **10 秒冷却**，期间所有请求都被拒绝。那是演示站的限制，不是软件的。

`demo` 角色只读。它不能管理身份池、改设置、建 API Key，也不能发起下载；
调试台里的 `explain` 和 `identity` 是 operator 专属，因为这两个都会交回一份实时凭据。
你在上面做的任何事下一个人都看得到 —— 把它当公共沙箱，**不要往里粘自己的 cookie**。
</Aside>

## 跑一个自己的

<Tabs>
  <TabItem label="Docker" icon="seti:docker">
    ```bash
    git clone https://github.com/Evil0ctal/Douyin_TikTok_Download_API.git
    cd Douyin_TikTok_Download_API
    cp .env.example .env          # 然后设置 DTK_SECRET_KEY
    COMPOSE_ENV_FILES=.env docker compose -p dtk -f docker/compose.yml up -d
    ```

    打开 `http://localhost:8000`，在浏览器里完成初始化。
    完整版在[快速开始](/zh/quickstart/)。
  </TabItem>
  <TabItem label="一键脚本" icon="seti:powershell">
    一个 bash 脚本，会识别你的发行版、给出对应的 Docker 安装方式、按机器大小调好
    容器上限、生成密钥、把整套跑起来。再跑一次它就变成运维菜单：
    状态、升级、改口令、备份、改设置、清磁盘。

    ```bash
    bash <(curl -fsSL https://raw.githubusercontent.com/Evil0ctal/Douyin_TikTok_Download_API/main/install/install.zh.sh)
    ```

    英文版是 `install/install.sh`。两份都在[安装与部署](/zh/installation/)里有说明。
  </TabItem>
</Tabs>
