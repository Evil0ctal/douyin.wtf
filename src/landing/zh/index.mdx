## 这是什么

**Douyin_TikTok_Download_API** 是一个开源、自部署的[抖音](https://www.douyin.com)、
[TikTok](https://www.tiktok.com) 数据接口服务。你用一条 `docker compose up`
把它跑在自己的机器上。没有托管版、不用注册、没有配额，链路上也没有第三方。

它能取两个平台的作品、作者、评论、合集和搜索，下载视频和图集时拿到的是**无水印**的流
—— 它挑的是平台本来就提供的那条干净流，而不是「去掉」了什么。采集到的内容归档在
你自己的 PostgreSQL 里，所以上游删掉的作品，本地还读得到。

<CardGrid stagger>
  <Card title="三个入口，一套逻辑" icon="puzzle">
    93 个操作的 REST 接口、给 AI agent 用的 MCP 服务端、以及 `dtk` 命令行。
    MCP 不是在 HTTP 上再包一层：三者调的是同一个 service 层。
  </Card>
  <Card title="cookie 不再是负担" icon="approve-check">
    无头浏览器按时铸造游客身份，池子自己测试、冷却和退休它们。
    你自己的登录态 cookie 是可选增强，不是前提。
  </Card>
  <Card title="签名是纯 Python" icon="seti:python">
    `a_bogus`、`X-Bogus` 和 TikTok 的签名都在进程内算，微秒级。
    浏览器只作兜底，以及用来发现算法漂移。
  </Card>
  <Card title="它会告诉你自己不舒服" icon="warning">
    每次请求都有结构化记录，每个身份和每个端点都有实时健康度。
    风控信号会在池子烧穿之前触发熔断。
  </Card>
</CardGrid>

## 不用装任何东西就能试

[https://demo.douyin.wtf](https://demo.douyin.wtf) 是一个对所有人开放的在线实例。登录页会替你填好演示账号，
进去之后控制台和接口都能用。

它只是一台小服务器，所以有限流：**每 10 秒 30 次请求**，超了会进入 10 秒冷却，
期间所有请求都会被拒绝。那是演示站的限制，不是软件的 —— 你自己的实例限额由你定。
